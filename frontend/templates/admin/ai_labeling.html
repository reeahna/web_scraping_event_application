Models

Each model has its own free quota. The main model is always tried first. A backup model (off unless GROQ_FALLBACK_MODEL is set) is used only while the main model is rate limited. It only gives a provisional category to events the main model has never labeled: it never hides an event, never replaces a main-model label or an administrator's choice, and every event it labels stays in the main model's queue to be verified.
